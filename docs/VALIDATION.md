# Prüfung dieser Quellcode-Veröffentlichung

Stand: 12. November 2026. Desktop 3.7.0, Stream-Deck-Plugin 1.0.0, Server 2.3.2, Android-Control 1.0.0, Robot-SchichtLog 1.8.0. Die Ergebnisse beziehen sich auf die bereinigte Exportkopie und die unten genannten lokalen Prüfungen, nicht auf eine neue Installation bei beliebigen Drittanbietern. Diese Revision erweitert ausschließlich den Desktop um Website-Aufrufe. Server, Stream-Deck-Plugin und Android-Quellen bleiben gegenüber dem geprüften Stand vom 10. November unverändert; ihre folgenden Prüfergebnisse stammen von diesem Stand.

Die Prüfung verwendete vorhandene lokale Abhängigkeiten außerhalb des Exportordners. `node_modules`, Build-Ausgaben, Testdatenbanken, Testprotokolle, lokale SDK-Pfade und Signierdateien sind nicht im Repository enthalten. Git bewahrt die Quellbytes, damit die Quellhashes der selbst erzeugten BetterDiscord-Brücke unverändert bleiben.

Discord-Rechte, reale TikTok-Verfügbarkeit, Musik in einem echten Sprachkanal, Spotify-Wiedergabe, eine gedrückte Stream-Deck-Hardwaretaste sowie Ton/Pop-up auf einem konkreten Android-Handy hängen von der eigenen Installation ab und werden durch diese automatisierten Prüfungen nicht garantiert. Die ergänzende Oberflächenprüfung umfasst ausschließlich die oben beschriebene Besucherübersicht. Die native Bedienung und ihr Screenshot wurden während der Prüfung angesehen; ein Bildschirmfoto mit privaten Statistikwerten wird nicht veröffentlicht. Auch ein erfolgreicher Quellbuild ist keine signierte, auf dem Zielgerät geprüfte APK. Die persönliche App-Verteilung bleibt getrennt von dieser Veröffentlichung.
