Zur VerwaltungZum Spotify-Player

Nur für Administratoren

Melde dich mit deinem bestätigten Administratorkonto an.

Zur Anmeldung

Lokale Vorschau: Hier keine echten Spotify-Zugangsdaten eingeben. Die Verbindung wird auf dem eingerichteten Server aktiviert.

1. Spotify-App vorbereiten

  1. Öffne deine App im Spotify Developer Dashboard.
  2. Trage die hier angezeigte Callback-Adresse dort exakt als Redirect URI ein.
  3. Übernimm Client ID und Client Secret in das Formular und speichere sie.

Die Adresse stammt aus der Serverkonfiguration. Bei einer falschen Domain muss die Betreiberadresse am Server berichtigt werden.

Spotify Premium ist für den Browserplayer erforderlich. Im Development Mode sind bis zu fünf ausdrücklich zugelassene Spotify-Konten möglich. Trage sie im Spotify-Dashboard ein; eine Website-Freigabe ersetzt diese Zulassung nicht.

2. Zugangsdaten speichern

Leer lassen, um das vorhandene Secret bei gleicher Client ID zu behalten. Bei einer anderen Client ID ist ein neues Secret erforderlich. Gespeicherte Secrets werden nicht zurückgegeben.

Eine gespeicherte Änderung trennt bestehende Spotify-Verbindungen. Nutzer verbinden ihr Spotify-Konto anschließend erneut.

3. Zugangsdaten prüfen

Die Prüfung verwendet ausschließlich die bereits gespeicherten App-Zugangsdaten. Sie bestätigt weder die Premium-Mitgliedschaft noch die Freigabe einzelner Nutzer.

Noch keine Prüfung in dieser Ansicht durchgeführt.
